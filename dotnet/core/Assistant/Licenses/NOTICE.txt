NLTK inference code adapted to C# from NLTK 3.10.4 (2026-11-18). Original project: https://github.com/nltk/nltk; Copyright 2001-2026 NLTK Project.
Perceptron inference based on NLTK Matthew Honnibal implementation; model distributed by NLTK data as MIT-licensed (https://github.com/sloria/textblob-aptagger).
WordNet 3.0 Copyright 2006 Princeton University.
English stopwords: Snowball (BSD-3-Clause), https://snowballstem.org/algorithms/english/stop.txt; https://snowballstem.org/license.html. Application modifications retain modal content words and suppress contraction fragments. NLTK stopwords corpus is not redistributed.
The gzip model contains only public English linguistic data; no Box/application documents.
